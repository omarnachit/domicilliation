# Domiciliation SaaS - Platform Features & Core Functionality

## Overview
Complete domiciliation platform offering business address services, company formation, tax/accounting management, and physical workspace access in Morocco.

---

## 🎯 Core Feature Modules

### 1. Accès Domicilié (Reception & Management)

#### 1.1 Client Portal (24/7)
**Self-service dashboard for domiciled clients**

**Daily Mail/Fax/Package Management:**
- ✅ Daily scans of all received mail/fax/packages
- ✅ Categorized sorting: Fiscal, Registered (Recommandé), Commercial, Administrative
- ✅ Secure PDF downloads with encryption
- ✅ Infinite document history (5-year legal retention + unlimited optional)
- ✅ Full-text search across scanned documents (OCR)
- ✅ Batch download capability (monthly archives)

**Real-time Notifications:**
- 📱 Multi-channel alerts: Push notifications, Email, SMS
- 📱 Instant notifications when mail/packages arrive
- 📱 Customizable notification preferences per category
- 📱 Priority alerts for registered/fiscal mail
- 📱 Daily/weekly digest options

**Forwarding Services:**
- 📮 Physical mail forwarding (monthly or on-demand)
- 📮 Destination: Anywhere in Morocco or international
- 📮 Postage options: Client-paid or prepaid
- 📮 Tracking numbers for all forwarded items
- 📮 Forwarding schedule management (e.g., "every 15th of month")

#### 1.2 Physical Access Management
**On-site visit and pickup system**

**Access Hours:**
- 🕐 6 days/week: 8:30 AM - 6:30 PM (Monday-Saturday)
- 🕐 Closed Sundays and public holidays

**QR Code Pickup System:**
- 📱 Clients book pickups via portal
- 📱 Generate time-slot QR code
- 📱 Scan at reception for instant verification
- 📱 No-show tracking and reminder system

**Security & Logging:**
- 📸 Photo capture of all packages at reception
- 📸 Visitor log with photo ID verification
- 📸 Digital signature on pickup confirmation
- 📸 Real-time admin alerts for suspicious activity

## 💾 Core Technical Features

### Tech Stack
- **Frontend**: Next.js 16 + React 19 + TypeScript
- **UI**: Tailwind CSS 4 + Radix UI + Framer Motion
- **Backend**: Supabase (PostgreSQL + Auth + Storage)
- **Forms**: React Hook Form + Zod validation
- **Payments**: CMI / PayZone / Stripe integration

### Database Schema Enhancements

#### Payment Flexibility
```sql
CREATE TABLE payment_plans (
  id UUID PRIMARY KEY,
  contract_id UUID REFERENCES contracts(id),
  billing_frequency TEXT CHECK (billing_frequency IN ('annual', 'monthly', 'one_time')),
  amount DECIMAL(10,2),
  currency TEXT DEFAULT 'MAD',
  tva_rate DECIMAL(5,2) DEFAULT 20.00,
  auto_renew BOOLEAN DEFAULT true,
  next_payment_date DATE,
  payment_method TEXT CHECK (payment_method IN ('card', 'transfer', 'cash', 'check'))
);
```

#### Categorized Mail System
```sql
CREATE TABLE mail_items (
  id UUID PRIMARY KEY,
  company_id UUID REFERENCES companies(id),
  category TEXT CHECK (category IN ('fiscal', 'registered', 'commercial', 'administrative', 'unknown')),
  priority TEXT DEFAULT 'normal' CHECK (priority IN ('urgent', 'high', 'normal', 'low')),
  auto_categorized BOOLEAN DEFAULT false,
  scan_url TEXT,
  ocr_text TEXT,
  arrival_date TIMESTAMPTZ,
  notification_sent BOOLEAN DEFAULT false
);
```

#### QR Code Pickup System
```sql
CREATE TABLE pickup_appointments (
  id UUID PRIMARY KEY,
  company_id UUID REFERENCES companies(id),
  appointment_date TIMESTAMPTZ,
  qr_code TEXT UNIQUE,
  status TEXT CHECK (status IN ('scheduled', 'completed', 'no_show', 'cancelled')),
  authorized_person_id UUID REFERENCES authorized_persons(id),
  items_to_pickup JSONB,
  checked_in_at TIMESTAMPTZ,
  photo_log_url TEXT
);
```

#### Formation Service Tracking
```sql
CREATE TABLE company_formations (
  id UUID PRIMARY KEY,
  company_id UUID REFERENCES companies(id),
  formation_package TEXT CHECK (formation_package IN ('creation_complete', 'formalites')),
  status TEXT CHECK (status IN ('pending', 'in_progress', 'completed', 'blocked')),
  certificat_negatif_done BOOLEAN DEFAULT false,
  statuts_done BOOLEAN DEFAULT false,
  rc_done BOOLEAN DEFAULT false,
  if_done BOOLEAN DEFAULT false,
  cnss_done BOOLEAN DEFAULT false,
  ice_done BOOLEAN DEFAULT false,
  annonce_presse_done BOOLEAN DEFAULT false,
  estimated_completion DATE,
  assigned_specialist UUID
);
```

#### Tax/Accounting Services
```sql
CREATE TABLE tax_declarations (
  id UUID PRIMARY KEY,
  company_id UUID REFERENCES companies(id),
  declaration_type TEXT CHECK (declaration_type IN ('tva', 'ir', 'is', 'cnss', 'damancom')),
  period_start DATE,
  period_end DATE,
  filing_deadline DATE,
  status TEXT CHECK (status IN ('draft', 'ready', 'filed', 'late')),
  teledeclaration_reference TEXT,
  filed_at TIMESTAMPTZ,
  auto_filed BOOLEAN DEFAULT false
);
```
